# astrbot_plugin_feiyu_video

让 bot 真的「看」视频：抽关键帧交给视觉模型，再用她自己的口吻讲出来。

## 人格设定里要写什么（装了之后必看）

这个插件**不直接提供给模型的工具**，它把自己的动作注册进
[`astrbot_plugin_persona_mind`](../astrbot_plugin_persona_mind) 的 `feiyu` 入口。所以：

1. **必须同时装 `persona_mind`。** 只装本插件时，模型那边一个动作都看不到 —— 不是坏了，是没有入口。
2. **人格设定里只写「什么时候该动手」，不要写 `feiyu(...)`、`action=`、`target=` 或任何参数名。**
   参数格式由插件在真要动手的那一轮临时告诉她（`engine/specs.py` + `engine/selector.py`），
   写进人格只会变成「同一件事两处说法」，而且插件启停时人格不会跟着变。
3. 人格里有这么几行，本插件才会被自然调用：

- 丢视频链接或文件、「这讲了啥」「画面里那几个是谁」→ **看视频**
- 顺着上一段画面追问「刚才那个人是谁」→ **认人**

### 可以直接粘贴的一段

只装本插件时，把下面这几行加进人格设定的末尾就够了：

```
- 发来链接、问「这讲了啥」「画面里那几个是谁」→ 去看那段画面，用我自己的话讲
- 顺着上一段画面追问「刚才那个人是谁」→ 认一下
```

**不要**改成 `feiyu(action="...")` 那种写法——参数格式由插件在真要动手的那一轮临时给她。

**反例**（这些不该触发）：裸的「说说」、「评论区」单独出现、她说「我去看看」但没给具体目标。

完整的原理、可逐字复制的人格段落、写入脚本，见 [persona_mind/README.md](../astrbot_plugin_persona_mind/README.md#让她自然地用这些本事人格设定里要写什么)。


## 怎么用

**平时就说话，不用记指令。** 左边是你说的，右边是她真会做的：

| 你这么说 | 她做什么 |
| --- | --- |
| 甩一条 B 站 / 抖音链接，加一句「这讲了啥」 | 去下片、拿台词、按台词密度挑画面，用她自己的话讲 |
| 「你看下这个 BV 号」 | 同上，不需要你说「看视频」这三个字 |
| 「刚才那个人是谁」「那张图里是什么」 | 认上一段画面 |
| 发了本地视频文件，什么都没说 | 也会去看（只发文件不打字也算） |

**指令形式**（一样有效，适合明确指定）：

- `/看视频 <链接或路径>`
- `/识图` 认上一张图

**她不会做的**：没让她看，她不会自己跑去刷视频；视频里没有台词时会直接说「这次没拿到字幕」，不会编。

## 特性

- **自动抽帧**：按 `frames` 均匀抽帧，可调宽度压体积，超长视频受 `max_seconds` 限制
- **模型直读**：抽出的帧作为多模态消息交给视觉模型，不需要额外部署
- **认不出会补证**：画面识别不了时用百度识图认物、必要时联网补背景
- **口吻重写**：可选把「事实描述」重写成人格说话方式，避免念说明书
- **两种入口**：群里直接甩视频，或 `/看视频 <路径或链接>`

## 听得见话也看得见画面（1.4.0）

以前她只能看画面，弹幕里说她「内容没回传」那次就是这个原因：**画面能截，话听不见**。

现在两样都给：

| 拿到什么 | 怎么拿 | 给她的形态 |
|---|---|---|
| 台词 | B站页面内 `x/player/v2` 取 AI 字幕列表 → 后台带 `Referer` 拉正文（**不需要 cookie**，`auth_key` 已在链接里） | 自然段连排的引文，**全文不摘要**；超预算按段均匀挑，开头明说「这是节选」 |
| 画面 | 480p 下整片（25 分钟片实测 45 秒）→ 按**台词密度**选点 → 定点抽帧 | N 张图，跟着这一轮请求走，不写进历史 |

几个反直觉但要紧的地方：

- **AI 字幕没有标点**。3400 字连成一坨既难读也不好引，所以按口语节奏补标点（`engine/subs.punctuate`）：收尾是「吗呢吧啊啦了么哦哈呀嘛」且攒够字数就断句，攒到短语长度就给逗号。**只加标点，一个实词都不动。**
- **抽帧不再等间隔**。等间隔会把人像演讲的一段拍 20 张、把最热闹的一段一张都不拍。现在按 20 秒窗口算密度（字数、cue 频率、数字专名、切镜），一半给密度峰、一半保底锚点，相邻帧保证最小间距。没有字幕才退回等间隔。
- **覆盖率不够就如实说**。字幕只覆盖 25% 的时候，末尾会带一句「大概只覆盖了前半部分」——她会照着转述，而不是假装全听到了。
- **拿不到就直说拿不到**。「这次没拿到字幕」/「画面这次没跟上」/「两样都没取到」三种说法写在注入里，不许编。
- **不要以为 `_t` 可以省**。`x/player/v2` 有 CDN 缓存，不加时间戳会拿到**上一条视频**的字幕（实测覆盖时长比本片还长）。同理，bsk 复用旧标签页时页面可能还是上一条，所以拿到 bvid 要和目标对一遍，对不上就当没有。

配置里新加两项：`subs_enable`（读台词，默认开）、`subs_inject_tokens`（台词最多念多少 token，默认 6000）。`see_shots` 默认从 3 调到 10、`see_timeout` 从 90 调到 180——全片下载 + 抽帧一般 40–90 秒。

设计文档（含实测数据、预算表、降级阶梯、验收场景）：[docs/watch-v3-design.md](docs/watch-v3-design.md)。

## 网页链接也能看（1.2.0）

以前只认两样东西：QQ 发来的视频文件、直链 mp4。别人甩一条 `https://www.bilibili.com/video/BV...` 或抖音分享链，她会当成文件去下载，下回来一堆 HTML，然后说「这个视频打不开」。

现在遇到页面链接，按两条路走：

1. **yt-dlp 下前 N 秒**（默认 30 秒、480p）——B 站这类能直接下的，2 秒就能拿到画面
2. **下不下来就让浏览器去看**——用 bsk 打开页面，找到 `video` 元素，把画面区域按时间截几张图（默认 4 张），连标题和简介一起交给视觉模型

第二条是关键：抖音这类站点不给 cookies 就不发视频流（`Fresh cookies (not necessarily logged in) are needed`），而浏览器里是登录状态，页面能正常播——截图就等于「真的看了」。截完会用 video 元素的坐标裁掉黑边和推荐栏，只留画面。

| 站点 | 走哪条 |
|---|---|
| B站（含 b23.tv 短链） | yt-dlp |
| 抖音（含 v.douyin.com 短链） | 直接走浏览器截帧（没配 cookies 时不白试 yt-dlp） |
| 快手 / 小红书 / YouTube | 没配 cookies 直接浏览器；配了就先 yt-dlp |
| 直链 .mp4 / .webm | 直接下载抽帧（老路） |

相关配置：`yt_dlp`、`ytdlp_seconds`、`ytdlp_height`、`cookies_browser`、`browser_fallback`、`browser_shots`、`browser_settle`。

## 从插件市场装（1.4.3）

插件市场里搜 `大肥鱼·看视频` 或 `astrbot_plugin_feiyu_video`。**装之前先看一眼这三条**，它们决定了它能不能用：

| 要什么 | 为什么 | 缺了会怎样 |
|---|---|---|
| **`astrbot_plugin_persona_mind`** | 本插件不直接给模型工具，它把「看视频 / 认人」注册进 persona_mind 的 `feiyu` 入口 | 模型那边一个动作都看不到，不是坏了，是没有入口 |
| **`bsk`（browser-skill 的浏览器 CLI）** | 字幕列表只能从「已登录的 B 站页面」里问出来（`x/player/v2` 要登录态），后台直连拿不到 | 拿不到字幕，只剩画面；页面截帧那条路也一起没了 |
| **`yt-dlp` + `ffmpeg`** | 下载整片、定点抽帧 | 完全看不了视频 |

`yt-dlp` 会自动找 PATH 和常见安装位置，也可以在本插件配置里指定绝对路径（`yt_dlp`）；
`ffmpeg` 用 `imageio-ffmpeg` 自带的那个，不需要另装。

**系统要求**：Windows / Linux 都行，但**字幕这条路依赖 bsk**，而 bsk 目前只有 Windows + Edge/Chrome 扩展版。
没有 bsk 的机器上，本插件会退化成「抽帧看画面」，不会报错。

**装完必须做的一件事**：人格设定里写「什么时候该动手」——见上面
[人格设定里要写什么](#人格设定里要写什么装了之后必看)。不写的话，她不知道什么时候该调用它。

## 安装

1. `pip install -r requirements.txt`（`imageio-ffmpeg`、`Pillow`）
2. 想看 B 站这类链接，还要 `pip install yt-dlp`（不装也能用：抖音走浏览器，其他站点会提示「得先装 yt-dlp」）
3. 目录放到 `astrbot/data/plugins/`
4. 配置里填 `vision_provider_id`（AstrBot 里已配好的多模态模型 id）
5. 重启 AstrBot

## 配置

| 键 | 说明 |
| --- | --- |
| `vision_provider_id` | 视觉模型 id，例如 `deepseek/deepseek-vision` |
| `frames` / `max_seconds` / `frame_width` | 抽帧数量、时长上限、帧宽度 |
| `rewrite` / `rewrite_provider` | 是否重写成口吻、用哪个文本模型 |
| `history_turns` | 参考最近几轮对话来判断「这视频」指什么 |
| `image_search` | 认不出时用识图（需 bsk 可用） |
| `bsk_path` / `bsk_browser` | bsk 路径与实例，留空自动发现 |
| `search_key` / `search_api` | 联网搜索，留空则关闭 |

## 常见问题

**报 ffmpeg 相关错误**
`imageio-ffmpeg` 没装或没下载到二进制，重装一次即可。

**说「看不到视频」**
`vision_provider_id` 填错，或模型不支持图片输入。看日志里 provider 的实际返回。

**很慢/很贵**
调小 `frames` 和 `frame_width`，或调小 `max_seconds`。

## 安全边界

这条链路会驱动 bsk（日常那个浏览器，带登录态），所以做了闸门：

- 只认上表里的站点域名（按 host 后缀匹配，`bilibili.com.evil.com`、`evil.com/?u=bilibili.com` 都不算）
- 内网地址一律拒：`127.*`、`10.*`、`192.168.*`、`169.254.*`、`172.16-31.*`、`localhost`
- 直链媒体文件（`.mp4` 等）也放行，但同样过内网过滤

想加站点就改 `_PLATFORM_HOSTS`，别把闸门删了。

## 让她自己看（1.2.2）

默认打开 `see_with_llm`。收到视频或 B 站/抖音这类页面链接时，插件只负责把画面取出来（yt-dlp 下前 30 秒，或开浏览器截帧），然后把这些帧**直接放进这一次的模型请求**，主模型自己看、自己说。

- 前提：主模型多模态。AstrBot 的 provider 配置里 `modalities` 要含 `image`，否则框架会在请求前把图片丢掉（`tool_loop_agent_runner.py` 里那层判断）。
- 主模型不是多模态时自动退回旧行为：插件用 `vision_provider_id` 看完，转成事实，再用 `_speak` 换她的口气说一遍。
- 同一条链接 10 分钟内复用缓存帧；一次最多 3 帧；单条链接最多等 180 秒。
